# IBM Bob 2.0 Hackathon Submission Readiness Checklist

Use this checklist before submitting your project on September 27 at 11:00 PM Malaysia time (15:00 UTC).

---

## 1. Prototype & Codebase

- [ ] **Working Prototype**: The prototype runs reliably and executes the demonstrated workflow end-to-end.
- [ ] **No Secrets / Tokens**: Verify `.env`, API keys, or private tokens are not committed to git.
- [ ] **Clean Git History**: Commits pushed from feature branch (`jish` / `coreen`) and merged cleanly to `main`.
- [ ] **Dependencies & Setup**: Clear setup instructions in `README.md` if any runtime is needed later.

---

## 2. IBM Bob Task Session Screenshots (`bob_sessions/`)

- [ ] Opened Bob IDE.
- [ ] Navigated to **Tasks**.
- [ ] Selected the relevant task and opened it.
- [ ] Clicked the task header to display the **Task session consumption summary**.
- [ ] Captured screenshot of the summary in PNG format.
- [ ] Saved the screenshot into the [`bob_sessions/`](file:///bob_sessions/) directory.
- [ ] Repeated for all core prototype tasks.
- [ ] Checked that image files are committed and render properly in markdown/GitHub.

---

## 3. Evidence of Problem & Improvement

- [ ] **Before Section**: Concrete, measurable pain points described (e.g., *"tracing callers across 40 files takes 45 minutes manually"*).
- [ ] **After Section**: Explicit explanation of how IBM Bob 2.0 automates and streamlines the steps.
- [ ] **Impact Section**: Hard numbers and percentages (e.g., *"reduces blast radius discovery time from 45 mins to 2 mins — a 95% reduction"*).

---

## 4. Demonstration & Video Flow

- [ ] **Problem Introduction**: Show the manual pain point.
- [ ] **Existing Workflow**: Highlight the friction.
- [ ] **Our Solution**: Introduce the tool and interface.
- [ ] **IBM Bob Integration**: Clearly show Bob IDE running the task, prompts, and skills.
- [ ] **Workflow Completion**: Show end-to-end output (e.g., generated report, decision dossier, or resume briefing).
- [ ] **Measured Impact**: Conclude with time and error reduction metrics.

---

## 5. Dataset & Ethical Compliance

- [ ] All datasets used are public or synthetic with appropriate licenses.
- [ ] No company confidential data.
- [ ] No client data or PII.
- [ ] Documented dataset sources included in the submission documentation.
